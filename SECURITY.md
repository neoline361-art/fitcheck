# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 3.2.x   | ✅ |
| 3.1.x   | ✅ (security fixes only) |
| < 3.0   | ❌ |

## No Telemetry, No Network Access

FitCheck does not collect telemetry, send usage data, or make outbound network calls. All computation runs locally on your machine.

## Vulnerability Reporting

If you discover a security vulnerability, please report it privately:

- **Email**: [neoline361@gmail.com](mailto:neoline361@gmail.com)
- **GitHub**: Open a draft security advisory under the Security tab

Do not disclose security vulnerabilities publicly until they have been addressed.

## Preferred Encryption

PGP key available on request.

## Dependency Scanning

Dependencies are audited via `pip-audit` in CI on every commit.

## Disclosure Process

1. Report received — acknowledgment within 48 hours
2. Investigation — fix developed within 7 days
3. Patch release — published with advisory
4. Public disclosure — 30 days after patch
